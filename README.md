תקציר הפרויקט - באנגלית :
Frigate is an open-source NVR (Network Video Recorder) tool that allows its users to connect, view and record their local and network cameras.
Our addition is a feature that gives the users the ability to monitor their long-term saved video segments and to avoid redundant video exports.
